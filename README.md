# 🏝️ Conheça PE - PWA

## 📱 Descrição
PWA que utiliza **geolocalização** para mostrar informações sobre cidades de Pernambuco. Desenvolvido como atividade acadêmica para a discplina de Coding Mobile.

## 🎯 Funcionalidades
- ✅ **PWA** - Instalável e funciona offline
- ✅ **Geolocalização** - Detecta cidade do usuário
- ✅ **Informações Locais** - Dados sobre cidades de PE
- ✅ **Interface Simples** - Fácil de usar
- ✅ **Design Responsivo** - Mobile-first

## 🛠 Tecnologias
- HTML5, CSS3, JavaScript
- Service Worker
- Web App Manifest  
- Geolocation API
- OpenStreetMap Nominatim API

## 🚀 Como Usar
1. **Acesse** o app no navegador
2. **Clique** em "Descobrir Minha Cidade"
3. **Permita** o acesso à localização
4. **Veja** informações sobre sua cidade
5. **Instale** como PWA (menu do navegador)

## 🌐 API Utilizada
**OpenStreetMap Nominatim API**
- Finalidade: Converter coordenadas em nome da cidade
- Endpoint: `https://nominatim.openstreetmap.org/reverse`
- Uso: Geolocalização reversa

## 📋 Requisitos Atendidos
- ✅ PWA (Progressive Web App)
- ✅ Recurso de hardware (Geolocalização) 
- ✅ API pública (OpenStreetMap)
- ✅ Não é app de clima
